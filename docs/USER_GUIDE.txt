OFFLINE VOICE STUDIO
User Guide
Created by Jerome Ventigan

OVERVIEW
Offline Voice Studio records microphone or Windows speaker audio, transcribes local audio or video files, and converts text to speech. Processing stays on this computer. The app does not download models or send audio to a service.

SPEECH TO TEXT TAB
1. Choose an audio source (system audio or microphone).
2. Select Start Recording, speak or play audio, then Stop Recording.
3. Recordings are saved in Documents\Offline Voice Studio\Recordings.
4. Select Open Audio/Video to choose an existing file.
5. Leave Music / lyrics unchecked for speech; enable it for sung vocals.
6. Select Transcribe Recording. Progress shows preparation, speaker detection/model loading, and estimated transcription progress.
7. Select Save Transcript to export the text.

SPEAKER LABELS
Speech transcripts are labeled Speaker 1, Speaker 2, and so on when local diarization detects speakers. If no speakers are detected, labels are shown as Speaker unknown. Music / lyrics mode skips speaker detection and labels segments Music / vocals.

TEXT TO SPEECH TAB
1. Type or paste text into the text area, or use Open Text File to load a .txt file.
2. Use Append Transcript to add the current transcript without overwriting existing text.
3. Choose a voice, rate, and volume.
4. Select Speak Transcript or Speak Selection.
5. The spoken chunk is highlighted in the text area while it plays.
6. Select Stop Speaking to cancel.
7. Select Save Spoken Audio to export speech as a WAV file.
8. Use Install Voices to open Windows Speech settings and add more voices.

THEMES
Use the Theme dropdown in the header to switch between Light, Dark, System, Solarized, Nord, and High Contrast. System follows the Windows light/dark setting.

OFFLINE MODEL AND RUNTIME
The installer includes the Faster-Whisper model, FFmpeg, speaker-detection runtime, and ONNX speaker models. No model folder selection or internet connection is required. User-selected audio, model, recording, and transcript paths must be on a local drive; network paths are rejected.

TROUBLESHOOTING
- If the waveform stays flat, check the selected audio source and confirm that computer audio is playing or the microphone is active.
- If no speech is detected, try Music / lyrics mode for singing or check that the selected source contains audible speech.
- Video transcription uses the audio track only; it does not read text displayed in the picture.
- Speech output uses Windows built-in voices. Install more via the Install Voices button.
- For support, note the error shown and the selected audio format.
